# Cybersecurity Field Guide

A beginner-friendly, defensive cybersecurity learning website. It introduces
common cyberattacks, warning signs, practical defenses, and a short interactive
knowledge check.

## Open the site

Open `index.html` in a browser. The site runs locally without installation and
includes a simplified attack lifecycle, searchable attack topics, warning signs,
practical defenses, and a four-question quiz with answer explanations.

The page uses locally stored HTML, CSS, and JavaScript. It does not send data
anywhere. Its explanations are high-level and intended for awareness and
protection, not for carrying out attacks.
