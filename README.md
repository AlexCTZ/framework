# Cybersecurity Field Guide

A beginner-friendly, defensive cybersecurity learning website. It introduces
common cyberattacks, warning signs, practical defenses, and a short interactive
knowledge check. It also explains the MITRE ATT&CK framework with a defensive
walkthrough, an embedded official Enterprise Matrix, practical usage guidance,
and interactive exercises.

## Open the site

Open `index.html` in a browser. The site runs locally without installation and
includes a simplified attack lifecycle, searchable attack topics, warning signs,
practical defenses, a four-question quiz, and an introduction to MITRE ATT&CK
with guidance on using the matrix, a live reference to the official Enterprise
Matrix, a fictional case study, and three exercises. The embedded matrix is
hosted by MITRE and requires an internet connection; a direct link is provided
if embedding is unavailable in your browser.

The page uses locally stored HTML, CSS, and JavaScript. It does not send data
anywhere. Its explanations are high-level and intended for awareness and
protection, not for carrying out attacks.
